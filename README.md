# Phishing URL Risk Analyser

COMP3000 Computing Project — BSc (Hons) Computer Science

**Student:** Jacob Askew
**Supervisor:** Dr Nancy Girdhar

## Project vision

This project is aimed at people without specialist cybersecurity
knowledge who are unsure whether to trust an unfamiliar link.

It will produce a website where someone can enter a URL, identify
the actual domain and receive a risk assessment with a plain-language
explanation of any warning signs. The tool will examine the address
without visiting the destination. Its results will make clear that
URL analysis alone cannot guarantee that a website is safe.

The project will use labelled URL examples to test whether a
machine-learning classifier identifies phishing links more effectively
than a set of manually defined rules. Evaluation will examine both
missed phishing links and false alarms, including examples from
domains excluded from training.

## Project status

Project initiation and planning. The software has not yet been implemented.
